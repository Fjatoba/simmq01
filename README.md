# Simulado de revisão integrada — Métodos Quantitativos

Atividade em dupla com análise no **jamovi**: 9 partes, 21 questões, 110 minutos sugeridos, 20 pontos. Aplicação em 25/11/2026.

**Acesso dos estudantes:** https://fjatoba.github.io/simmq01/apresentacao.html.

## Páginas

| Página | Para que serve |
|---|---|
| [`apresentacao.html`](apresentacao.html) | Porta de entrada: objetivo, passo a passo, distribuição do tempo, o que se espera das respostas e perguntas frequentes. |
| [`index.html`](index.html) | O simulado. As duplas escolhem a versão (A–H), baixam a base, respondem (salvamento automático no navegador) e geram o PDF de entrega. |
| [`glossario.html`](glossario.html) | Glossário didático com 73 termos, tabela de símbolos e busca. |
| [`aula-revisao.html`](aula-revisao.html) | Aula de revisão de 60 minutos, da pergunta à conclusão. |
| [`caderno_simulado_para_impressao.pdf`](caderno_simulado_para_impressao.pdf) | Caderno em branco para impressão. |

## Dados

A pasta [`bases_csv/`](bases_csv/) contém oito bases **sintéticas** paralelas (`base_revisao_versao_A.csv` … `H.csv`, de 96 a 110 casos e 18 variáveis) e o `dicionario_variaveis.csv`. Os dados são fictícios e servem apenas para fins didáticos.

## Entrega

Cada dupla anexa no Google Classroom:

1. o PDF gerado pelo botão **“Salvar PDF para entregar”**;
2. o arquivo `.omv` do jamovi com as análises usadas nas respostas.

## Publicação no GitHub Pages

1. Envie **todo o conteúdo desta pasta** para a raiz de um repositório público, incluindo o arquivo oculto `.nojekyll` e a pasta `bases_csv`.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, depois `main` e `/ (root)`, e salve.
3. Depois de 1 a 2 minutos, abra o endereço indicado. Teste o download de um CSV e a geração do PDF.

As páginas são HTML autônomo: não usam fontes, scripts nem serviços externos.

## O que não está neste repositório

Os gabaritos e o guia do professor **não** são publicados aqui, porque o repositório é público. A correção comentada para as duplas é postada no Classroom depois do simulado.
